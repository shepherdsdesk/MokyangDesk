홈페이지 관리자

여기서 고친 내용은 GitHub의 홈페이지 저장소에 저장되고, 1~2분 뒤 홈페이지에 나타납니다.

이 컴퓨터(브라우저)에만 저장되고, 다른 곳으로 보내지지 않습니다.
접근 키 만드는 법 (처음 한 번)
  1. GitHub 로그인 → 오른쪽 위 사진 → Settings
  2. 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. 이름은 “홈페이지 관리자”, 기간은 1년 정도
  4. Repository access: Only select repositories → mokyangdesk
  5. Permissions → Repository permissions → Contents: Read and write
  6. 만들어진 키(github_pat_…)를 복사해 위 칸에 붙여 넣기

키 없이 둘러보기로 들어가면 고친 내용을 파일로 받아 GitHub에 직접 올릴 수 있습니다.
