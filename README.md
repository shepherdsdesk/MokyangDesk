## 주소 바꾸기
각 파일 맨 아래 `var LINKS = { ... }` 부분만 고치면 됩니다.
주소가 비어 있는 버튼은 화면에 '준비 중'으로 표시됩니다.

- four-cuts.html → `download`(프로그램 받기), `guide`(사용 설명서)
- prayer-walk.html → `copy`(사본 만들기), `guide`(설치 설명서)
