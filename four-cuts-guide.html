이것만 있으면 됩니다

프로그램 값은 들지 않습니다. 결제나 회원 가입도 없습니다.

태블릿

아이패드 또는 갤럭시탭. 앞 카메라가 있는 기기면 됩니다. 휴대폰이나 노트북으로도 열립니다.

거치대

사람 눈높이에 화면이 오도록 세웁니다. 서서 찍을 때는 가슴 높이 정도가 좋습니다.

사진 프린터

4×6(10×15cm) 인화가 되고 AirPrint(아이패드)나 Mopria(갤럭시탭)를 지원하는 프린터입니다.

인화지·충전기

예상 인원보다 넉넉한 인화지와 잉크, 태블릿 충전기와 멀티탭을 챙깁니다.

2 · 설치

내 휴대폰·태블릿 홈 화면에 추가하기

앱 스토어에서 받는 앱이 아니라, 주소를 홈 화면에 아이콘으로 저장해 앱처럼 쓰는 방식입니다. 무료이고 1분이면 됩니다. 인터넷이 되는 곳에서 한 번 해 두면 행사 당일에는 인터넷 없이도 열립니다.

  1. 1

    사파리로 주소 열기

    반드시 사파리(Safari)로 엽니다. 카카오톡이나 네이버 앱 안에서 열렸다면 오른쪽 아래·위 메뉴에서 “Safari로 열기”를 누르세요.

  2. 2

    공유 버튼 누르기

    공유 버튼을 누릅니다. 아이폰은 화면 아래쪽, 아이패드는 주소창 오른쪽에 있습니다. 공유 버튼이 안 보이면 주소창 옆 •••을 먼저 누르세요.

  3. 3

    “홈 화면에 추가” 누르기

    목록을 아래로 내리면 ⊞ 홈 화면에 추가가 있습니다. “웹 앱으로 열기” 스위치가 보이면 켜 둡니다.

  4. 4

    이름 확인 후 “추가”

    이름은 네컷부스로 두고 오른쪽 위 추가를 누르면 홈 화면에 아이콘이 생깁니다.

  5. 5

    아이콘으로 열고 카메라 허용

    앞으로는 사파리가 아니라 홈 화면 아이콘으로 엽니다. 처음 촬영할 때 카메라 권한을 묻으면 허용을 누르세요.

  1. 1

    크롬으로 주소 열기

    크롬(Chrome)으로 엽니다. 카카오톡 안에서 열렸다면 오른쪽 위 메뉴에서 “다른 브라우저로 열기”를 누르고 크롬을 고르세요.

  2. 2

    메뉴 누르기

    주소창 오른쪽의 ⋮ 메뉴를 누릅니다.

  3. 3

    “홈 화면에 추가” 누르기

    홈 화면에 추가 또는 앱 설치를 누릅니다. 이어서 나오는 창에서 설치 또는 추가를 고릅니다.

  4. 4

    아이콘 위치 정하기

    “홈 화면에 추가” 창이 한 번 더 나오면 추가를 누르거나 아이콘을 끌어다 원하는 자리에 놓습니다.

  5. 5

    아이콘으로 열고 카메라 허용

    홈 화면의 네컷부스 아이콘으로 열고, 카메라 권한을 묻으면 앱 사용 중에만 허용을 누르세요.

  1. 1

    삼성 인터넷으로 주소 열기

    갤럭시에 기본으로 깔린 삼성 인터넷으로 엽니다.

  2. 2

    메뉴 누르기

    화면 아래쪽의 ≡ 메뉴를 누릅니다. 주소창에 ⤓ 설치 아이콘이 보이면 그것을 눌러도 됩니다.

  3. 3

    “현재 페이지 추가” → “홈 화면”

    ＋ 현재 페이지 추가를 누르고 홈 화면을 고릅니다.

  4. 4

    “추가” 누르기

    이름을 확인하고 추가를 누르면 홈 화면에 아이콘이 생깁니다.

  5. 5

    아이콘으로 열고 카메라 허용

    아이콘으로 열고, 카메라 권한을 묻으면 허용을 누르세요.

잘 되었는지 확인

아이콘으로 열었을 때 주소창 없이 화면 전체가 앱처럼 보이면 성공입니다.

새 버전 받기

앱이 고쳐지면 인터넷이 되는 곳에서 아이콘을 한두 번 다시 열면 저절로 새 버전으로 바뀝니다.

지우고 싶을 때

홈 화면 아이콘을 길게 눌러 삭제합니다. 다른 앱이나 사진에는 아무 영향이 없습니다.

✅
첫 화면 오른쪽 위에 “✓ 오프라인 사용 가능”이 보이면 준비가 끝났습니다. 행사 전에 비행기 모드로 바꾸고 앱을 열어 촬영이 되는지 꼭 시험해 보세요.
ℹ️
앱 파일만 내려받아 태블릿에서 열면 카메라가 켜지지 않습니다. 카메라는 보안상 https:// 주소에서만 켜지므로, 반드시 앱 주소로 열어서 홈 화면에 추가하세요.
3 · 행사 전 설정

우리 행사에 맞게 꾸미기

첫 화면 오른쪽 위 ⚙️를 누릅니다. 고른 내용은 자동으로 저장되고, 오른쪽 미리보기에 인쇄될 모습이 바로 나옵니다.

⏱️ 촬영 타이머

한 컷마다 기다리는 시간입니다. 3초 · 5초 · 8초 · 10초 중에서 고릅니다. 아이들이나 단체 사진은 8초 이상을 권합니다.

🧩 레이아웃

스트립 2줄은 한 장에 같은 사진이 두 줄로 나와, 가운데를 잘라 2명이 나눠 갖습니다. 2×2 그리드는 한 장 전체를 쓰는 큰 사진입니다.

🎨 프레임 색상

화이트, 블랙, 핑크, 하늘, 크림, 민트 중에서 고릅니다. 직접 만든 프레임 이미지를 넣을 수도 있습니다. 프레임 만들기 →

✏️ 하단 문구

큰 문구에는 행사 이름을, 작은 문구에는 말씀 구절을 넣습니다. 날짜는 자동으로 들어가고, 끌 수도 있습니다.

📷 카메라

성도님이 스스로 찍을 때는 앞 카메라를, 봉사자가 찍어 줄 때는 뒤 카메라를 고릅니다. 거울처럼 좌우반전도 켤 수 있습니다.

🔧 기타

사진 모서리 둥글게, 가운데 자르는 선, 카운트다운 효과음을 켜고 끌 수 있습니다.

촬영 시작

카운트다운

사진 앱에 저장하기

완성 화면에서 📥 사진 앱에 저장을 누릅니다. 기기마다 저장되는 곳이 조금 다릅니다.

갤럭시탭 · 안드로이드저장 버튼을 누르면 바로 저장갤러리 앱의 Download 앨범
ℹ️
아이패드는 보안 정책 때문에 웹앱이 사진 앱에 바로 저장할 수 없습니다. 그래서 매번 공유 창에서 “이미지 저장”을 한 번 눌러야 합니다.
6 · 인쇄

인터넷 없이 인화하기

인쇄에는 인터넷이 필요 없습니다. 태블릿과 프린터가 같은 Wi‑Fi에 있기만 하면 됩니다.

방법 A

같은 공유기에 연결

인터넷이 안 되는 공유기라도 괜찮습니다. 태블릿과 프린터를 같은 Wi‑Fi에 연결합니다.

방법 B

프린터 Wi‑Fi에 직접

프린터가 자체 Wi‑Fi를 만드는 다이렉트 모드를 지원하면, 태블릿을 그 Wi‑Fi에 바로 연결합니다.

인쇄 창 설정

4×6 · 여백 없음

완성 화면에서 🖨️ 인쇄하기를 누르고, 용지 4×6(10×15cm), 여백 없음을 고릅니다.

💡
아이패드에서 인쇄 버튼을 눌러도 창이 안 열리면 📥 저장 버튼 → 공유 창의 “프린트”를 쓰세요. 가장 확실한 방법입니다.

같은 크기로 꾸미기

템플릿을 바탕에 깔고, 위 그림과 같은 크기로 디자인합니다. 회색 칸에 사진이 들어갑니다.

ℹ️
처음이라면 배경으로 깔기를 권합니다. 투명 처리 없이 디자인만 하면 사진이 그 위에 올라갑니다. 프레임에 행사 이름을 이미 넣었다면 설정에서 “문구 표시”를 끄세요. 프레임은 레이아웃마다 따로 태블릿에 저장되어 인터넷 없이도 유지됩니다.
8 · 자주 묻는 질문

이럴 땐 이렇게

카메라 화면이 까맣게 나와요

카메라 권한이 막혀 있을 수 있습니다. 아이패드는 설정 → Safari → 카메라를 허용으로 바꿉니다. 갤럭시탭은 주소창 왼쪽 자물쇠 → 권한 → 카메라를 허용으로 바꿉니다. 다른 앱(카메라, 영상통화)이 카메라를 쓰고 있다면 닫아 주세요.

“이 주소에서는 카메라를 쓸 수 없어요”라고 나와요

앱 파일을 직접 열었거나 https가 아닌 주소로 열었을 때 나오는 안내입니다. 위에 있는 앱 주소로 다시 열고 홈 화면에 추가하세요.

사진이 사진 앱에 안 보여요

아이패드는 공유 창에서 “이미지 저장”을 눌러야 사진 앱에 들어갑니다. 갤럭시탭은 갤러리 앱의 Download 앨범을 확인하세요.

인쇄 창에 프린터가 안 보여요

태블릿과 프린터가 같은 Wi‑Fi에 연결되어 있는지 확인하세요. 프린터가 AirPrint(아이패드) 또는 Mopria(갤럭시탭)를 지원하는지도 확인해 주세요. 프린터를 껐다 켜면 보이는 경우도 많습니다.

인쇄했더니 여백이 생기거나 사진이 작아요

인쇄 창에서 용지를 4×6(10×15cm), 여백을 없음(테두리 없음)으로 고르세요. 프린터 앱에 따로 용지 설정이 있다면 그곳도 4×6으로 맞춥니다.

넣어 둔 프레임이 사라졌어요

브라우저의 방문 기록이나 웹사이트 데이터를 지우면 프레임과 설정도 함께 지워집니다. 프레임 이미지 원본을 태블릿 사진 앱이나 파일 앱에 보관해 두었다가 다시 넣으세요.

화면이 자꾸 꺼져요

앱이 켜져 있는 동안 화면 꺼짐을 막지만, 기기에 따라 안 될 수 있습니다. 행사 중에는 기기 설정에서 자동 잠금을 “안 함”으로 바꿔 두세요.
